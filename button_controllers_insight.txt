### 1. DirectionController Class (direction_controller.py)

class DirectionController:
    def __init__(self):
        # Direction control state variables
        self.last_fb = None           # Stores FORWARD/BACKWARD/PAUSE
        self.last_lr = None           # Stores LEFT/RIGHT
        
        # Button control state variables
        self.button_states = {
            'button_a': None,         # Stores BUTTON_A or None
            'button_b': None,         # Stores BUTTON_B or None  
            'button_c': None          # Stores BUTTON_C or None
        }
        
        # Gesture mapping configuration
        self.gesture_mappings = {
            "Open_Palm": "BACKWARD",
            "Closed_Fist": "FORWARD", 
            "Thumb_Up": "BUTTON_A",
            "Thumb_Down": "BUTTON_B",
            "Pointing_Up": "BUTTON_C",
            "Right_Elbow_Extended": "RIGHT",
            "Right_Elbow_Bent": "LEFT"
        }
```

================================================================================
🔄 COMMAND FLOW PROCESS
================================================================================

1. GESTURE DETECTION
   - MediaPipe detects gestures: Open_Palm, Closed_Fist, Thumb_Up, etc.
   - Confidence score must be > 0.5 for button detection

2. COMMAND MAPPING
   - Gestures mapped via self.gesture_mappings dictionary
   - Dynamic configuration loaded from runtime_gesture_config.json

3. VARIABLE STORAGE
   - Forward/Backward: stored in DirectionController.last_fb
   - Left/Right: stored in DirectionController.last_lr
   - Buttons: stored in DirectionController.button_states

4. GUI UPDATE
   - Commands passed to DirectionGUI.update_commands()
   - GUI variables updated: current_fb, current_lr, button_states
   - Visual display refreshed every 100ms

5. CONSOLE OUTPUT
   - Commands printed: print(f"{fb_text}, {lr_text}")
   - Button states logged: print(f"[DIRECTION] Button states updated: {self.button_states}")

================================================================================
💾 PERSISTENCE & STORAGE
================================================================================

### CONFIGURATION FILES (Static Storage):
- gesture_config.json         - User saved gesture mappings
- runtime_gesture_config.json - Active runtime configuration

### RUNTIME VARIABLES (Dynamic Storage):
- Commands stored ONLY in memory during execution
- NO permanent logging to files or databases
- Commands are TEMPORARY and reset when person unlocked

def update_commands(self, fb_command, lr_command, button_states):
    self.current_fb = fb_command if fb_command else "None"
    self.current_lr = lr_command if lr_command else "None"
    if button_states:
        self.button_states = button_states

================================================================================
⚡ REAL-TIME BEHAVIOR
================================================================================

### COMMAND LIFECYCLE:
1. Gesture detected by MediaPipe
2. Mapped to command via gesture_mappings
3. Stored in DirectionController variables
4. Passed to DirectionGUI for display
5. Printed to console for logging
6. Reset when person unlocked or system stops

### KEY CHARACTERISTICS:
- Commands are LIVE (updated every frame)
- Storage is TEMPORARY (memory only)
- State RESETS when person unlocked
- NO historical logging (only current state)
- Minimum confidence 0.5 for button detection
- Hold duration 0.8 seconds for forward/backward commands

def _analyze_button_gestures(self, main_gesture_results, current_time):
    # Reset button states
    new_button_states = {'button_a': None, 'button_b': None, 'button_c': None}
    
    # Check each detected hand gesture
    for hand_data in all_hands_data:
        gesture_name = hand_data.get('gesture', 'None')
        score = hand_data.get('score', 0.0)
        
        if score < 0.5:  # Minimum confidence threshold
            continue
            
        # Check mapping and update state
        mapped_command = self.gesture_mappings.get(gesture_name, 'NONE')
        if mapped_command == 'BUTTON_A':
            new_button_states['button_a'] = 'BUTTON_A'
        elif mapped_command == 'BUTTON_B':
            new_button_states['button_b'] = 'BUTTON_B'
        elif mapped_command == 'BUTTON_C':
            new_button_states['button_c'] = 'BUTTON_C'
```

📝 SUMMARY
================================================================================

YES, gesture control commands ARE stored in variables:

✓ RUNTIME-ONLY storage (in memory, not saved to files)
✓ TEMPORARY storage (reset when unlocked)
✓ LIVE-UPDATED (change with each gesture detection)
✓ ACCESSIBLE through DirectionController and DirectionGUI instances
✓ BUTTON STATES tracked individually (button_a, button_b, button_c)
✓ CONSOLE LOGGING for debugging and monitoring

The system maintains current command state but does NOT create persistent logs
or historical storage of command sequences. All control states exist only
during active system runtime and reset when the person tracker is unlocked
or the application terminates.
